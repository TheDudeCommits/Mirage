# AI Image Detector Backend

## Overview

This is a Flask-based web application that provides an AI-powered image detection service to identify whether images are generated by AI or are authentic. The system is designed as a backend API for the AskMira platform, featuring a machine learning model that analyzes images using patch-based detection techniques. The application provides both a REST API for programmatic access and a web interface for testing purposes.

## User Preferences

Preferred communication style: Simple, everyday language.

## System Architecture

### Backend Framework
- **Flask Application**: Core web framework handling HTTP requests and responses
- **WSGI Configuration**: Uses ProxyFix middleware for proper header handling in production environments
- **CORS Support**: Enabled for cross-origin API access

### AI Detection Engine
- **PyTorch Model**: Uses a pre-trained model (SuSy.pt) for AI image classification
- **Patch-Based Analysis**: Divides images into 224x224 pixel patches for detailed analysis
- **Feature Extraction**: Employs Gray-Level Co-occurrence Matrix (GLCM) for texture analysis
- **Multi-Class Classification**: Supports detection of various AI generation models including DALL-E 3, Midjourney, Stable Diffusion, and authentic images

### Image Processing Pipeline
- **PIL Integration**: Handles image loading, cropping, and basic transformations
- **Tensor Operations**: Converts image data to PyTorch tensors for model inference
- **Texture Analysis**: Uses scikit-image for advanced feature extraction
- **Visualization**: Matplotlib integration for generating analysis visualizations

### File Upload Management
- **Secure File Handling**: Validates file extensions and uses secure filename generation
- **Size Limits**: Configurable maximum file size (16MB default)
- **Temporary Storage**: Upload directory for processing images

### Frontend Interface
- **Bootstrap UI**: Modern, responsive web interface for testing
- **JavaScript Integration**: Client-side functionality for form handling and API communication
- **Real-time Feedback**: Loading indicators and error handling for user experience

### API Design
- **RESTful Endpoints**: Clean API structure for image analysis requests
- **JSON Responses**: Structured data format for analysis results
- **Error Handling**: Comprehensive error reporting and logging
