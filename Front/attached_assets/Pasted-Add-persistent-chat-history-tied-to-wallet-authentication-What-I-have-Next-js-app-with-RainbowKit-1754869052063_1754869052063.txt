Tech choices (please implement):
Auth: RainbowKit + SIWE + NextAuth (no Twitter/Google). Use @rainbow-me/rainbowkit-siwe-next-auth.

Add /api/auth/[...nextauth] with the SIWE Credentials provider as in RainbowKit’s SIWE example.

Store session in a cookie (JWT).

Database: Neon Postgres (hosted). Use Prisma.

Install: prisma @prisma/client

Use env DATABASE_URL for the Neon connection string.

Create models and migration.

Schema (Prisma) — create exactly this:

model User {
  id            String   @id @default(cuid())
  walletAddress String   @unique
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt
  chats         Chat[]
}
model Chat {
  id        String   @id @default(cuid())
  userId    String
  user      User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  title     String
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
  messages  Message[]
  @@index([userId, updatedAt])
}
model Message {
  id        String   @id @default(cuid())
  chatId    String
  chat      Chat     @relation(fields: [chatId], references: [id], onDelete: Cascade)
  role      String   // 'user' | 'assistant' | 'system'
  content   String   // markdown/text
  createdAt DateTime @default(now())
  @@index([chatId, createdAt])
}
API routes (App Router) — create:

POST /api/chats → create chat { title } and return chat.

GET /api/chats → list current user’s chats (most recent first, cursor pagination with ?cursor=).

PATCH /api/chats/:id → rename chat.

DELETE /api/chats/:id → delete chat + messages.

GET /api/chats/:id/messages → list messages (cursor).

POST /api/chats/:id/messages → append message { role, content }.
All routes must require NextAuth session and map session.user.walletAddress to a User row (create on first use).
